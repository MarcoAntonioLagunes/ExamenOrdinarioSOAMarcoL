# Servicio SOAP de Alumnos

## Requisitos
- Python 3.x
- MySQL en localhost con base de datos `uav` y tabla `alumnos`.

Instala dependencias:

```bash
pip install -r requirements.txt
```

Ejecuta el servicio:

```bash
python soap_alumnos.py
```

El servicio quedará escuchando en:

- URL: http://localhost:8000/soap
